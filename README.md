# 2026-time-table

> [!NOTE]
> This project is in a very early stage of development.

### Usage

This project requires [Git](https://git-scm.com/) and [Bun](https://bun.sh/) to be installed.

- `$ git clone https://github.com/hastebrot/2026-time-table`
- `$ cd 2026-time-table/sources/timetable-app/`
- `$ bun install`
- `$ bun run dev --port 1234`
- `$ bun run test --watch`
- `$ bun run fmt --write`
- `$ bun run lint --fix`
